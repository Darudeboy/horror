# Audio placeholders

В первой версии клипы не обязательны. Игра не ссылается на отсутствующие `.wav`/`.ogg`.
События шума для ИИ (`AudioManager.emit_noise`) независимы от громкости в настройках.

Планируемые слоты: вентиляция, светильники, шаги игрока/врага, принтер, телефон, считыватель, дверь, щит, турникет, лифт.
